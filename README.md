# Weekend Challenge: Map it (AWS Builder Center)

> **Event Window:** October 30, 2026 – November 2, 2026 | **Status:** Live  
> **Challenge Type:** Weekend Rapid Sprint (approx. 72 Hours)  
> **Hosting Platform:** AWS Builder Center  
> **Core Theme:** *"Data is easier to understand when you can see it on a map. This weekend, put some on one."*

---

## 📌 Executive Summary

The **Weekend Challenge: Map it** is a high-velocity, 72-hour community hackathon focused on geospatial intelligence and location-aware applications. The goal is to take a rich, real-world dataset (open government data, environmental feeds, mobility metrics, disaster information, etc.), process its spatial attributes, and render it into an interactive, visually stunning map application using **AWS Location and Data Services**.

## 🚀 Quick Launch (How to Use This Plan)

1. Review [`plan/01_CHALLENGE_OVERVIEW.md`](./plan/01_CHALLENGE_OVERVIEW.md) for hard constraints and deadlines.
2. Select your project concept from [`plan/02_PROJECT_IDEAS.md`](./plan/02_PROJECT_IDEAS.md) (we strongly recommend **EcoRoute: Clean Energy & EV Grid Navigator**).
3. Follow the AWS provisioning steps in [`plan/STARTER_TEMPLATES.md`](./plan/STARTER_TEMPLATES.md) to initialize your Amazon Location Service Map and Cognito unauthenticated identity pool.
4. Execute according to the 72-hour timeline in [`plan/05_IMPLEMENTATION_ROADMAP.md`](./plan/05_IMPLEMENTATION_ROADMAP.md).
5. Deploy to AWS Amplify Hosting / CloudFront + S3 and record your 3-minute video using [`plan/06_SUBMISSION_AND_DEMO_GUIDE.md`](./plan/06_SUBMISSION_AND_DEMO_GUIDE.md).
